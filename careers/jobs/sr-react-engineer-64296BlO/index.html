Join #Octosteam!

We are a company focused on custom software development and have been in the market for over 19 years. At Octosteches we are dedicated to finding highly specialized talent to work with large companies in the United States, Europe, and Canada.

Each one of our collaborators works with different teams and colleagues around the world, in the design and commercialization of software. We look forward to having you as part of our team in the role of Senior React Engineer.

What you will do
  • Design, develop, and maintain scalable frontend applications using React.js.
  • Own features end-to-end, from technical design to implementation and deployment.
  • Make informed technical decisions, balancing performance, scalability, and maintainability.
  • Collaborate closely with backend and design teams to define API contracts and user experiences.
  • Ensure high code quality through testing, code reviews, and best practices.
  • Identify and drive improvements in performance, architecture, and developer experience.
  • Provide guidance and mentorship to junior team members when needed.
  • Leverage AI-powered tools to enhance productivity in coding, debugging, documentation, and code reviews.

Required Qualifications

  • 6+ years of experience in frontend development.
  • Strong expertise in React.js (Hooks, Context API, component architecture).
  • Solid experience with Next.js (SSR/SSG) and modern frontend patterns.
  • Advanced proficiency in JavaScript (ES6+) and TypeScript.
  • Experience with state management libraries (Redux Toolkit, Zustand, or similar).
  • Strong understanding of responsive design, accessibility (WCAG), and cross-browser compatibility.
  • Experience integrating REST and/or GraphQL APIs.
  • Hands-on experience with testing frameworks (Jest, React Testing Library, Cypress, or similar).
  • Familiarity with Git workflows and modern build tools (Vite, Webpack).
  • Experience using AI tools (e.g., code assistants, automated documentation, or code review tools) to improve development workflows

Nice to Have

  • Experience with React Server Components.
  • Knowledge of performance optimization tools (Lighthouse, React Profiler).
  • Exposure to micro-frontends or monorepo architectures.
  • Experience with Angular.
  • Experience with design systems and component libraries (Storybook).
  • Familiarity with real-time technologies (WebSockets, SSE).
  • Understanding of frontend security best practices (OAuth, JWT, XSS prevention).
